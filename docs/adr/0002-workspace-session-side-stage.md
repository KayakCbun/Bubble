# Workspace session lives in the side stage, not inside the run card

The main transcript shows a run card (the brief). Clicking it opens the overlay's existing extra pane as a read-only projection of that run: the anchored workspace user turn and its output, stopping before the next user turn. A running or waiting card uses the same run-scoped live buffer. This keeps completed calls distinct and bounds rendering cost even though runs within one main session may share an ACP workspace session. Workspace sessions and Markdown previews share a preferred 560-point side-stage width; the main transcript contracts when necessary so the complete overlay fits the current display. Each card stores an anchor to its workspace user turn. Markdown opened from the run projection is a one-level stack with a back control, not a second column.
